# Arise Esports Tournament Platform — V1

An online esports tournament platform for organizing and managing gaming tournaments.

## Status

Currently in development.

### Completed

* Project structure
* Esports design system
* Homepage UI
* Frontend setup with React + Vite
* Tournament listing and game sections
* Registration flow UI
* Payment/QR code section

### In Progress

* Backend API
* Database integration
* Tournament registration
* Admin dashboard
* Payment verification
* Notifications
* Leaderboards

## Supported Games

* BGMI
* Free Fire MAX
* Call of Duty
* Valorant

## Project Structure

```text
arise-esports-platform/
│
├── client/              # React + Vite frontend
│
├── server/              # Express + MongoDB backend
│
├── .gitignore
├── README.md
└── PLAN.md
```

## Client — Run Locally

```bash
cd client
npm install
npm run dev
```

## Server — Run Locally

```bash
cd server
npm install
npm run dev
```

The backend runs on:

```text
http://localhost:5000
```

## Frontend

The frontend is built using:

* React
* Vite
* JavaScript
* Tailwind CSS

## Backend

The backend uses:

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcryptjs
* CORS
* dotenv

## Features

* 🎮 Multiple game tournaments
* 🏆 Tournament listings
* 👥 Team and individual tournaments
* 📝 Tournament registration
* 💳 UPI payment
* 📱 QR code payment
* 🔢 Transaction ID submission
* 📊 Tournament leaderboard
* 📢 Announcements/notifications
* 🔐 Admin/organizer dashboard

## Environment Variables

Create a `.env` file inside the `server` directory.

Do **not** commit `.env` files, passwords, API keys, database credentials, or other secrets to GitHub.

## Design

Design tokens and branding configuration can be found in:

```text
client/src/index.css
client/src/config/branding.js
```
